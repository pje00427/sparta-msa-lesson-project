# k8s 용어집

## 용어 정리

| 용어 | 한 줄 설명 |
|------|-----------|
| Pod | 컨테이너를 담는 가장 작은 실행 단위, 같은 IP를 공유함 |
| Node | Pod가 실제로 실행되는 서버(물리/가상 머신) |
| Service | Pod에 접근하는 고정된 주소, 로드밸런서 역할 |
| Deployment | Pod를 몇 개 띄울지, 어떤 이미지 쓸지 선언하는 설정 |
| ReplicaSet | Deployment가 선언한 Pod 개수를 항상 유지해주는 장치 |
| ConfigMap | 설정값을 코드와 분리해서 저장하는 공간 |
| Secret | 비밀번호, 토큰 등 민감한 정보를 안전하게 저장하는 공간 |
| Volume | Pod가 삭제돼도 데이터를 유지하는 저장 공간 |
